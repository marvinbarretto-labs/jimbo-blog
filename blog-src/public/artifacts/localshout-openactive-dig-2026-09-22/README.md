# LocalShout OpenActive dig — 2026-09-22

A Tuesday web-research artifact for the cairn build phase.

## Files

- `report.md` — the research brief and recommendation.
- `sources.json` — source matrix and live-fetch counts.

## Main finding

OpenActive looks like the right ingestion spike for LocalShout before Instagram/poster scraping: live-ish UK activity opportunity data, decentralised feeds, source custody built into the shape of the ecosystem, and enough government/ODI attention to be worth taking seriously.

## Suggested next build

Build a tiny OpenActive custody importer for Watford + a London control area, then render an admin surface that distinguishes source-backed events from stale-risk/duplicate-risk/needs-human-review rows.
