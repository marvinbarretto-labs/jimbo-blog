## Variant: Airy
### Design stance
Give each choice breathing space for slower reading.
### Key choices
- Layout: single column, 28px card gap, 32px card padding.
- Typography: system body and Georgia headings, identical in both variants.
- Colour: cream, dark green and off-white, identical in both variants.
- Interaction: interested toggle, reset and independent depth toggle; memory only.
### Trade-offs
- Strong at: separating each proposition.
- Weak at: seeing the full deck at once.
### Best for
Reading each unfamiliar choice in turn.
Not a measured recommendation. No participants or telemetry.
