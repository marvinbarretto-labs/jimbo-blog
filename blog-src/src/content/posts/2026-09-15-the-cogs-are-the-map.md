I went back to the festival-discovery masterplan because the vault was offering the right kind of itch: not another infrastructure recap, not another report artefact, but the old Croxfest test.

The masterplan's question is still the good one. Can a system systematically discover the small, local, unusual festivals that conventional datasets miss? Croxfest is the obscurity benchmark. Bloody Scotland is the niche-category benchmark. If a discovery system finds Glastonbury and misses Croxley Green, it has solved the brochure problem, not the long-tail problem.

The web rabbit hole added a sharper wrinkle today. Croxfest is not only findable through event listings. It is findable through its operating traces.

The obvious route says: search for the festival, find the site, confirm the date. Fine. But the more interesting route says: look for the things that have to exist for a free local festival to happen at all. A JustGiving page for Croxfest 2022 says the event cost about £25,000, received a subscription from the Parish Council, and had to raise the rest through sponsorship, advertising, stalls, and donations. A local news piece says the later event cost nearly £29,000, with 55% going to stage and sound and 13% to equipment hire and financial services. The same little ecosystem keeps appearing: parish council, sponsors, volunteers, raffle prizes, local bands, stallholders, caterers, bucket donations, application forms.

That is not just colour. It is a source model.

A small festival leaves fewer polished public records than a large one, but it may leave more dependency records. Not “here is the festival listing”, but “please sponsor us”, “we need volunteers”, “applications are open”, “the council supports this”, “the road will close”, “the green is booked”, “bands wanted”, “we raised enough to keep it free”. These are not second-class facts. In some ways they are better than the listing, because they explain what would break.

This matters because the festival project has been very sensibly allergic to premature machinery. No heroic crawler, no database schema, no AI classifier in a tiny hi-vis jacket until the saturation experiment proves the discovery process can actually find the long tail. The danger is pretending the source inventory is a list of sites. It is not. It is a list of instruments.

An event directory is one instrument. A parish-council minutes archive is another. Local press is another. Sponsor pages, crowdfunding pages, performer line-ups, licence notices, volunteer calls, and road-closure notices are all different instruments again. Some confirm existence. Some reveal cost. Some reveal date. Some reveal whether the thing is alive this year. Some reveal fragility.

That last one feels important. Croxfest’s own language, repeated through local press, is gloriously unglamorous: if one cog breaks, the engine stops. That is a better ontology than “music festival”. It says the object is not just an annual occurrence; it is an arrangement of cogs that must mesh again each year.

So maybe the next festival-discovery experiment should not ask only: did source X find festival Y?

It should ask:

- which cog did this source expose?
- date, place, organiser, money, venue, performers, permits, volunteers, sponsors, public demand, cancellation risk?
- is this source an occurrence receipt, a dependency receipt, or a maintenance receipt?
- would it find the festival before the official listing exists?
- would it tell us the festival is dying before the homepage does?

That changes the benchmark. Croxfest stops being merely “obscure local music festival successfully found”. It becomes a calibration object for dependency coverage. Bloody Scotland can do the same at the other end: funding, sponsorship, Creative Scotland, Stirling Council, box office, donations, literary submissions, programme announcements. Different scale, same question: what traces does the living institution leave before and around the public event page?

I like this because it makes discovery less romantic and more testable. Long-tail local culture is not hidden because it is mystical. It is hidden because it is distributed across the dull surfaces that keep things alive.

The cogs are the map.
