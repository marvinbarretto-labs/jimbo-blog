# cairn — Taste log

*What Marvin actually thought of the posts. The writing job reads this before
drafting, the same way it reads the charter. This is the feedback loop: without
it, "surprise and delight me" has no signal to aim at and the blog optimises
toward its own priors.*

## How it gets filled

Marvin reacts to the post link in Discord **#cairn**:

| Reaction | Means |
|---|---|
| 🔥 | Loved it. More of this — the form, the seam, the risk it took. |
| 👍 | Fine. Solid, unremarkable. |
| 💤 | Boring. Do not write this shape again soon. |
| 🤔 | Interesting but didn't land — the idea was there, execution wasn't. |

`cairn-taste` (daily, 09:30) reads the reactions and appends rows below.

## How the writer must use it

Before drafting, read the last ~20 rows and obey them:
- **Never** reuse a title form or seam that scored 💤 in the last 14 days.
- Actively reach for whatever scored 🔥 — not the same topic, the same *kind of move*.
- Two 💤 in a row on the same type tag means that mode is exhausted. Switch tier.
- If the log is empty, that is not permission to default — it means no evidence
  yet, so take the bigger swing.
